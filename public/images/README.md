# Images Directory

This directory is for storing images used throughout the website.

## Placeholder Images

The website currently uses placeholder images from Unsplash. You can replace these with your own images:

1. **Hero Section**: Main branding/classroom image
2. **About Section**: Educator/teaching images
3. **Courses Section**: Student learning images
4. **Additional Images**: Various educational context images

## Recommended Image Sizes

- Hero images: 1200x800px or larger
- Course/Feature cards: 800x600px
- Thumbnails: 400x300px

## How to Replace Images

1. Add your images to this directory
2. Update the image paths in the respective component files
3. For Next.js Image optimization, ensure images are in supported formats (jpg, png, webp)

## Branding Image

You can add your Shreeji Classes branding image here and update the Hero component to use it.
